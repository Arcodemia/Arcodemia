# `object-fit:cover` הוא חיתוך שני

תמונת הקריסטלים יכולה להיות מושלמת ועדיין להיחתך בדף. `object-fit:cover`
מוסיף חיתוך משלו, מעבר למסגרת התמונה, והוא תלוי ביחס תיבת ה-hero.

**תיבת ה-hero היא תמיד 657px גובה ברוחב שולחני**, בעוד הרוחב משתנה —
ולכן היחס שלה נע בין 1.6 ל-2.9. נמדד מהדף בפועל:

| רוחב | נחתך |
|---|---|
| 1920×1080 | 22.5% מהגובה בכל צד |
| 1440×900 | 13.3% מהגובה |
| 1280×800 | 8.8% מהגובה |
| 834 | 7.3% מהרוחב |
| 360 | 15.5% מהרוחב |

**ההשלכה על [[hero-crystals]]:** גביש שחייב להיכנס במלואו ב-1920 מוגבל
ל-55% מגובה התמונה — ולכן הוא מוכרח לשבת קרוב למרכז האנכי, שם יושב
הטקסט. זה גיאומטרי, לא אסתטי. אי אפשר גם שלם, גם גדול, וגם בפינה.

**לפני כל רנדר מחדש:** `npm run check:crystals` — מחשב את החיתוך בכל
רוחב נפוץ בלי לרנדר.

## מלכודת בתוך המלכודת

בנייד נראה היה שהגביש נחתך בקצה הימני, וכבר תיקנתי את השוליים בגלל זה.
צילום **עם שכבות ההחשכה מוסתרות** הראה שהוא שלם לגמרי, במרחק 27px מהקצה —
מה שנראה כמו חיתוך היה הגרדיאנט שמעמעם את הקצה.

**לפני שמתקנים "חיתוך": לכבות את שכבות ההחשכה ולהסתכל על התמונה עצמה.**
