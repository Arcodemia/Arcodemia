# שלושה גבישים, שלושה כללים

`LAYERS.full` ב-`tools/render-crystals.cjs` מדליק את `a` ו-`b` בלבד.

## `a` — השמאלי. במיקום ובגודל המקוריים, וחתוך בשוליים

`pA(){ return vec3(-ax()*1.00, 0.75, 0.40); }` בגודל `2.10, 0.86`.

🔴 **אל תנסה "להשלים" אותו.** זה נוסה ב-27.8: המיקום נגזר מההיטל
והגביש אכן נכנס במלואו — אבל כדי לעשות את זה הוא **הוקטן ל-70%
והוזז פנימה**, וזה שינה את המראה. הלקוח: "הקריסטל מצד שמאל היה
שונה, תחזיר אותו למה שהוא היה".

**המראה גובר על השלמות.** גביש שנכנס מהשוליים וחתוך שם הוא חלק
מהקומפוזיציה — אותו דין כמו `b`.

## `b` — הימני העליון. נשאר בדיוק כפי שהוא

**כולל החיתוך בקצה.** זו בקשה מפורשת של הלקוח, לא פספוס.
**אל "תתקן" אותו.** יש בדיקה בסקריפט הבנייה שנופלת אם מישהו משנה את
הגדלים שלו.

## `c` — הקטן מלמטה. כבוי

מרכזו יושב מתחת לקצה התמונה, ולכן הוא נראה כמו "גביש שמתחיל להיווצר"
כשגוללים מעט. הלקוח ביקש להסיר.

## היסטוריה של שתי טעויות

1. **סבב אחד הבנתי הפוך** — הורדתי את `a` והשלמתי את `b`.
   ההבהרה: `a` "טיפה חתוך" וצריך להשלים, `b` להשאיר, `c` להוריד.
2. **ואז "השלמתי" את `a` יותר מדי** — הקטנתי והזזתי אותו. הוחזר.

**לפני שינוי גבישים — לוודא איזה גביש זה איזה, ולהשוות מול
התמונה הקודמת אחרי הרנדר.**

⚠️ הצינור אינו רנדר ישיר: [[hero-image-is-a-2d-composite]].
`npm run check:crystals` הוא **דוח** ולא מבחן — שניהם חתוכים בכוונה.
